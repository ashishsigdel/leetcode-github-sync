Create a GitHub token

You need a fine-grained token scoped to just the repository you're syncing to. It takes about a minute.

  1. Open github.com/settings/tokens and select Fine-grained tokens in the sidebar.
  2. Click Generate new token.
  3. Under Token name, enter something you'll recognise later — e.g. leetcode-sync.
  4. Add a Description if you like. This is optional and only for your own reference.
  5. Choose an Expiration. When it expires syncing stops working, and you'll need to generate a new token and paste it in again.
  6. Under Repository access, pick Only select repositories and select the repository you want your solutions committed to.
  7. Expand Permissions → Repository permissions, find Contents, and set it to Read and write. That is the only permission this extension needs.
  8. Click Generate token, copy the value, and paste it into the token field.

GitHub shows the token only once. Copy it before you leave that page — if you lose it you'll have to generate another.
